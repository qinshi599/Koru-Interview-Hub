# InterviewApp

InterviewApp is an open-source interview question practice platform for people preparing for technology roles in New Zealand and Australia.

The idea is simple: people can share interview questions they have encountered, organise them by category and difficulty, and practise answering them in one place. The project is intended to grow through community contributions and real interview experiences.

## Current Features

- User registration and login
- Browse technical interview questions
- Create, edit, view and delete questions
- Organise questions by category and difficulty
- Submit practice answers
- View previous answers and submission times
- View personal practice attempts

## Planned Features

- AI-assisted answer scoring and feedback
- Suggestions for improving interview answers
- More question categories for New Zealand and Australian workplaces
- Better progress tracking
- Community moderation and reporting
- Search and filtering

AI feedback is planned as part of the project roadmap. The current version focuses on the core question-sharing and practice workflow first.

## Why This Project Exists

Finding relevant interview practice can be difficult, especially when preparing for a local technology job market. InterviewApp aims to make it easier for people to share questions from real interviews and help each other prepare.

The project is also a practical learning project built with ASP.NET Core MVC, Entity Framework Core and SQLite.

## Technology

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
- Razor views
- Bootstrap

## Using the Platform

InterviewApp is intended to be used as an online platform. Once the hosted version is available, users will be able to visit the website, create an account, browse interview questions and practise without downloading the project.

The public website link will be added here after deployment.

## Project Structure

```text

Data/           Entity Framework database context and migrations
Models/         Questions, categories and practice attempts
Views/          Razor pages for the web interface
wwwroot/        CSS, JavaScript and static assets
```
